# CPU V0 -> V0.0.1 -> V0.1 — Mission.md (Vision & Souveraineté)

## 1. Raison d'être
Transformer `Codex Web GPT` (V0, pont mono-plateforme ChatGPT pour Codex seul) en **CPU — CLI-Plateformes-Unifié** :
- **Souveraineté réseau** : zéro télémétrie, zéro mise à jour forcée vers l'amont.
- **Universalité plateformes** : accès unifié aux plateformes occidentales (ChatGPT, Gemini, Claude, Grok, Muse), chinoises (DeepSeek, Qwen, Z.ai, Kimi, **Feishu/Lark** pour `dsh-superagent`) et locales (Sakana Fugu, LFM3 `:9931`, FreeLLMAPI `:31415`).
- **Universalité d'exécution (Paliers 1–3)** : passer du DOM fragile à `REA + API-Anything + agent-browser` (Web), puis `CLI-Anything + agent-desktop` (apps desktop téléchargées), puis un hub agnostique à tous les CLI (`Codex`, `Claude Code`, `OpenCode`, `Hermes Agent`, `OpenClaw`, `Pi`, `DeepSeek dsh`).

## 2. Principes non négociables (Héritage V4 -> V5)
1. **Améliorer étape par étape AVANT de fusionner** : chaque palier est prouvé par tests automatisés avant de passer au suivant.
2. **EGM (Elephant-Goldfish)** : la spec et le code portent toute la preuve de fonctionnement sans dépendre d'un contexte conversationnel caché.
3. **Zero Babysitting** : installation Windows persistante, construction reproductible et vérification de bout en bout.
